Позитивный метод проверяет сохранение и повторное чтение. Негативный — дубликаты, неверные значения, состояние и версию. Критический путь воспроизводит подбор, пять оценок, приём и завершение адаптации. Безопасность проверяет роли, владельца объекта, CSRF и защитные заголовки.

Интеграционная серия проверила шесть входов, двадцать таблиц, индивидуальные соли, десять публичных страниц, ограничения реестров, отклики и планы, публикацию, повторный отклик, версии карточки, назначение и перенос встречи, оценки, приём, адаптацию, Office-выгрузки, PDF и обратную связь. Измерения, статусы и времена сохранены в POSTGRES_RESULTS.json. Учётные данные и токены в протокол не включаются.

Для воспроизведения: npm ci, npm test, npm run build, npm run validate. Отдельная тестовая PostgreSQL и DATABASE_URL используются командой npm run test:postgres.
